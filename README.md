# Doctor G - Healthcare Platform

Doctor G is a modern, comprehensive healthcare and medical services web application built with React, TypeScript, Vite, and Tailwind CSS.

## 🚀 Features

- **Doctor Search & Appointments**: Search doctors by specialty, view profiles, and book appointments with live queue tracking.
- **Emergency Services**: Instant ambulance finding and emergency dispatch services.
- **Online Consultation & Telehealth**: Connect with doctors virtually.
- **Medical Store & Pharmacy**: Order medicines and healthcare products.
- **Diagnostics & Health Checkups**: Browse and schedule comprehensive health checkup packages.
- **Blood Bank**: Search for donors and blood availability by blood group and location.
- **Health Records & Reminders**: Manage digital health records, track vitals, and set medicine reminders.
- **Family Health Management**: Keep track of health profiles and history for family members.
- **Traditional Healing**: Access alternative and traditional medicine consultations.
- **Multi-language Support**: Multilingual support for broader accessibility.

## 🛠️ Tech Stack

- **Framework**: [React 18](https://react.dev/)
- **Build Tool**: [Vite](https://vitejs.dev/)
- **Language**: [TypeScript](https://www.typescriptlang.org/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Charts**: [Recharts](https://recharts.org/)

## 📦 Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) (v18 or higher recommended)
- `npm` or `yarn` / `pnpm`

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/Devansh-18155/DoctorG-.git
   cd DoctorG-
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the development server:
   ```bash
   npm run dev
   ```

4. Build for production:
   ```bash
   npm run build
   ```
